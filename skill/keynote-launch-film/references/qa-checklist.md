# 交片前自查清单

每次把片子（整片或单幕）交给用户之前，主线程逐条过一遍。这些全是连盈片前几轮里用户实际指出过的问题：先由我们自己挑掉，用户就只需要谈审美。

先跑 `python scripts/qa/sheet.py 片.mp4 总览.png --every 0.5`，在总览图上逐格看；有疑问的秒数用 `master.py --check` 出大图。

## 画面
- [ ] 没有整片或局部发白、发灰（HDR 没转？电影滤镜把白底压灰了？）
- [ ] 白底是真白（中性 246–255），不发绿、不发黄、不发粉
- [ ] 抠像边缘干净：没有绿边、残影、头发锯齿、椅子缺块、墙角污渍
- [ ] AI 生成的人脸没有变形；同一个人每个镜头长得一样（参考定妆照）
- [ ] AI 味检查：太亮太干净太网红的镜头 → 拿真实素材当参考重生成，或改成克制的灰银色调
- [ ] 没有生成平台水印（右下角）
- [ ] 产品画面里没有手
- [ ] 没有黑点、破洞、重影、跳帧（合拢缝、修过字的地方要重点看）
- [ ] 同一个镜头没有在全片重复出现（除非故意首尾呼应）
- [ ] 低清素材已还原或已删掉，没有糊的中景

## 禁用
- [ ] 禁用清单里的每一项都没出现（别家品牌字样、别家产品照片、第三方部件品牌）
- [ ] 用户点名「必须出现」的镜头都在，而且看得清（连盈：机器人焊接全景、升降/倾斜演示）

## 字
- [ ] 我们加的字只有黑/白/灰；素材原色没被改
- [ ] 中英字幕在亮背景、暗背景上都看得清；和台词时间对齐，不早出不晚收
- [ ] 中文没有孤字成行（「来。」单独一行），英文没有拼写错误
- [ ] 头衔、标签、大屏字的字体统一（等线 / Segoe UI Light），动效节奏统一（淡入 + 轻微上移）
- [ ] 数字与参数表、官网一致；专利数用企业自己的

## 节奏与声音
- [ ] 讲话镜头已放慢到约 0.85x，嘴型和声音不打架（露脸用配音时避开大特写的嘴）
- [ ] 硬模块确实快、一直在动；软模块确实慢、有呼吸；三→四幕那一秒静音还在
- [ ] 人物淡入淡出约 0.5s，不是硬切出现
- [ ] 配音响度统一（整体约 -16 LUFS），句间气口自然，没有被截断的字
- [ ] 物体落下有重量（接触帧轻震 + 声音），不轻飘

## 交付
- [ ] 旧版已备份到 `backup\`
- [ ] 文件名带版本号，已拷到桌面进度文件夹
- [ ] 回复用户时实话实说：改了什么、还有什么没解决（不要说「完美」）
