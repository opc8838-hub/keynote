# 故事：五幕骨架 + 中段模块库 + 文案规矩

## 五幕骨架（固定框架，2:30–2:50）

| 幕 | 时长 | 主讲 | 作用 | 气质 | 画面来源 |
|---|---|---|---|---|---|
| 一 舞台开场 | ~30s | 创始人 | 我是谁、从哪来、只专注什么 | 庄重 | 生成舞台 + 大屏动效 + 创始人上台 + 老照片/厂区 |
| 二 产品发布 | ~28s | 画面为主，创始人一两句 | 开灯揭幕，让主打产品像新品一样被郑重介绍 | 仪式感 | 开灯揭幕动效 → 产品发布片（即梦模板/零件合拢/参数大屏）→ 交棒 |
| 三 中段模块 A | ~35s | 骨干员工 1 | 「硬」：讲实力 | 快、硬核 | 实拍 + 代码动效 + 生成补镜，快剪 |
| 四 中段模块 B | ~40s | 骨干员工 2 | 「软」：讲人和温度 | 慢、暖 | 生成故事（定妆照锁脸）+ 真实产品 + 白底讲述 |
| 五 舞台回归 | ~29s | 创始人 | 成绩、专利、走向世界、最后一句 | 收束、宏大 | 大屏历程 + 专利墙 + 文字地球 + logo |

**全片一句话**先定（连盈：「让起居不便的人，重新拥有独立的生活」），每一幕都围绕它。

## 中段两个模块：可替换，但必须两块都有

两块的作用是让故事饱满：**一块硬、一块软**。前一块把节奏推到最高，后一块突然慢下来，形成一张一弛。具体讲什么按企业来选：

| 模块 | 硬/软 | 适合的企业 | 讲述人 | 画面 |
|---|---|---|---|---|
| 技术与制造 | 硬 | 有工厂、有工艺的制造业（国内强项，制造业一定要讲） | 技术总监/厂长 | 激光切割、焊接、零件爆炸合拢、测试数字 |
| 供应链与交付 | 硬 | 贸易、品牌方、多工厂协作 | 供应链/运营负责人 | 仓库、物流线、地图光弧、交付数字 |
| 品质与检测 | 硬 | 医疗器械、食品、精密件 | 品控负责人 | 检测仪器、卡尺、寿命测试、认证证书 |
| 研发与专利 | 硬 | 技术驱动型 | 研发负责人 | 实验室、图纸→实物、专利墙 |
| 设计与人文 | 软 | 产品直接服务人的（家居、康养、母婴） | 设计师 | 一个家庭的一天，产品改变一个瞬间 |
| 用户故事 | 软 | to C、口碑型 | 真实用户/客户代表 | 用户的生活场景，前后对比 |
| 服务与陪伴 | 软 | 服务型、售后重的 | 服务团队 | 上门、培训、回访的人与人瞬间 |
| 匠人与传承 | 软 | 老字号、手艺型 | 老师傅/二代 | 手部特写、老照片、师徒 |

选法：A 从「硬」里挑企业最强的一项，B 从「软」里挑最能落到「全片一句话」的一项。两块都讲不出来时，宁可在大纲阶段跟用户讨论，也不要硬凑。

## 每幕的标准写法

- 讲述人**全程旁白**，只偶尔露脸（每人 2–4 次、每次 2–3 秒），第一次露脸时左下角出细字头衔（中英，像 Jony Ive 出场）。
- 硬模块：0.6–1.2 秒一刀，卡音乐鼓点，画面一直在动（推/拉/平移），工艺镜头左上角出中英细字标签。
- 软模块：镜头 3–5 秒，叠化；先只有声音再露脸；人物先出**角色定妆照**，之后每个镜头都参考它。
- 每幕结尾留好接下一幕的钩子（交棒句、白光、同机位）。

## 转场（连盈片验证过、用户认可的）

| 位置 | 做法 |
|---|---|
| 片头 | 空白大屏推进 2 秒 → 灯亮 → 大屏 logo |
| 一→二 | 黑场里开灯揭幕：光束照出产品轮廓（不是圆形）→ 全屏白 → 叠到发布片第一帧 |
| 二→三（交棒） | 创始人说交棒句 → 从大屏特写拉开露出人 → 停顿 → 连续右推放大到大屏 → 渐白 → 进模块 A |
| 三→四（全片最关键） | 模块 A 最后一个部件落定「咚」→ **音乐骤停一秒** → 同机位同角度叠化：冷的车间 → 暖的卧室（Codex 出同机位两张图）→ 钢琴单音，讲述人先出声不露脸 |
| 四→五 | 暖光定格 → 光晕转白 → 回舞台 |
| 地球之后 | 呼吸般变白（不要扫光） |
| 片尾 | logo + 最后一句（全片最重的那句话）逐字出现 → 灯熄 → 黑场 |

## 文案规矩

- 短句，一句一个意思，少形容词。
- **先讲人，再讲技术**；数字只用有出处的（官网、画册、参数表），专利数用企业自己的。
- 留一句让人记住的话，放在软模块结尾并在片尾重复（连盈：「一张床，可以只是一张床。也可以是一个人，重新走向生活的起点。」）。
- 不要口号式结尾（连盈的「让天下起居不便人士更独立」被用户否掉）。
- 不提第三方品牌（「德国电控系统」，不说 DEWERT）。
- 中英对照，英文要地道、短，不逐字直译。
- 给配音的稿：数字写成汉字（「一百七十公斤」），产品型号写成念法（「L Y 六百」）。
