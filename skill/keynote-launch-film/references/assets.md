# 素材：六类清单 + 录音要求 + 禁用清单

拍好的素材永远不够覆盖整部片，但它们是 AI 补画面时最重要的参考。开工第一天把这份清单发给用户。

## 六类素材

| # | 类别 | 要什么 | 用在哪 |
|---|---|---|---|
| 01 | 公司素材 | 官网文字和视频、厂区环境、宣传册（PDF 原件）、资质证书、专利证书、过往与最新成绩、企业历程年份 | 第一幕、第五幕大屏 |
| 02 | 行业素材 | 制造/供应链过程实拍（横拍、4K60 可慢放裁切最好）、车间、仓库 | 硬模块 |
| 03 | 产品素材 | 参数表（以它为准）、白底渲染图（多角度）、**分层爆炸图**、展厅实拍的每个动作（升降、起背、旋转…） | 第二幕揭幕、零件合拢、参数大屏 |
| 04 | 员工代表 | 讲述人白底（或白布/任意干净背景）真人特写视频，多拍几段、几种状态（讲话、低头、微笑、看镜头外） | 露脸镜头 |
| 05 | 老板素材 | 创始人清晰正面照、全身照、舞台/活动照 | 生成上台、挥手、指大屏镜头 |
| 06 | 声音素材 | 每位讲述人录音，见下 | 克隆配音 |

## 录音要求（配音质量 80% 取决于这里）

连盈片配音是最弱的一环：创始人的音色来自一段微信语音，压缩严重。把下面这段原样发给用户：

> 每位讲话的人，请用手机自带录音机各录一段：
> 1. 找一个安静、小一点、有窗帘或软家具的房间（不要空旷会议室、不要开空调和风扇）。
> 2. 手机放在嘴前 20–30 厘米，别贴着嘴，别用耳机麦克风。
> 3. 用平时正常讲话的语气，念 40–60 秒稿子（我会给你一段，里面有数字和产品名）。念错了停一下重念那句就行。
> 4. 再用「开心、有感染力」的语气念一遍同样的稿子。
> 5. **直接发原文件（m4a / wav），不要发微信语音，也不要用微信转发压缩的版本。**

- 克隆时开 `need_noise_reduction` + `need_volume_normalization`。
- 克隆音色 7 天不用会被删，项目周期长要定期用一次。
- 若讲述人本身普通话或状态不理想，提出两个备选：真人对着提词稿直接念（同时拍露脸）；或选 MiniMax 系统音色当旁白。
- 全员普通话。

## 文件夹结构

```
<项目>\
  素材\公司 行业 产品 员工 老板 声音\     ← 用户给的原件，不动
  src_sdr\                                 ← HDR 转好的视频（hdr_to_sdr.py）
  clips\                                   ← 用户生成回来的视频，按镜头编号命名（S1、K3a、H8…）
  gen\batch1\                              ← Codex 生的图
  voice\script\<人>.txt  voice\v<n>\<人>\01.mp3 …
  sections\ACT1..5\                        ← 每幕脚本 + 交付 ACTn.mp4 / ACTn_lines.json / ACTn_说明.md
  final\master.py  final\work\
  backup\                                  ← 每版大改前的旧版
  AGENT_BRIEF.md                           ← 助手公共说明（禁用清单写在这里）
```
镜头编号前缀：S 舞台、P 产品、K 硬模块补镜、T 转场、H 软模块故事（H0 = 角色定妆照）。

## 禁用清单（每部片都建）

- 别家品牌的 logo、字样（连盈：展厅枕套和床尾垫上的别家品牌金字 → 用 Codex 去掉或按颜色压黑/inpaint）。
- 不是本企业产品的照片（宣传册里常混着别家的床、病床，例如连盈的粉色窗帘睡衣男那张）。
- 第三方核心部件的品牌字样（DEWERT 等，抹掉）。
- 生成平台水印（MiniMax 右下角水印，裁掉）。

写进 `AGENT_BRIEF.md`，带文件路径；交付前在总览图上逐格扫一遍。
