# 连盈科技秋季发布会 · 制作手记

一部 2 分 46 秒的企业发布会影片，由创始人第一人称讲述、人与 AI 共同导演完成；这个仓库是它的制作手记网站。

**在线查看**：https://opc8838-hub.github.io/keynote/

## 初衷

很多传统企业的创始人、董事长，也可以学会讲故事。发布会不是科技公司的专属。

- **老板第一人称**：讲发展历程、产品理念、技术、过往成绩与发展宏图
- **一场正式的产品发布**：开灯揭幕，让主打产品像新品一样被郑重介绍
- **骨干员工自述**：技术总监讲制造，总设计师讲人文、关怀和温暖

## 工作流：人做导演，AI 做导演助理和执行

1. **导演大纲与文稿**：人给方向，AI 写分镜和中英文稿；大纲定了再往下走
2. **素材资产收集与管理**：公司、行业、产品、员工、老板、声音六类素材，建禁用清单
3. **声音克隆与配音**：每人十几秒录音即可克隆，逐句生成、自带时长
4. **用 AI 补齐画面**：生图 + 图生视频；角色定妆照保证同一张脸；产品不让 AI 画，真人用真实视频
5. **代码做动效**：零件合拢、专利墙、文字地球、开灯揭幕
6. **分幕并行制作**：每幕独立脚本、独立交付，多个 AI 助手分头做
7. **总合成与迭代**：统一滤镜、中英字幕、响度和音乐；看片反馈，从 v1 改到 v7
